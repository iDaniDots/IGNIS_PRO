IoT

        
Internet de las Cosas: objetos físicos que recogen o intercambian información mediante una red.

Forma de comunicación entre circuitos que utiliza una línea de datos y otra de reloj.

RESUELVE TUS DUDAS

      
Antes de comenzar.

      
Respuestas breves para entender mejor las piezas del catálogo.

    

    

      

        ¿Cuál es la diferencia entre un sensor y un actuador?
        
El sensor obtiene información del entorno; el actuador realiza una acción. Un DHT11 mide temperatura y humedad, mientras que un buzzer produce sonido.

      

      

        ¿Por qué el proyecto necesita un ESP32?
        
El ESP32 ejecuta el programa, interpreta las entradas y coordina las salidas. También permite explorar la comunicación inalámbrica de los datos.

      

      

        ¿El BME280 y el BME680 hacen lo mismo?
        
Ambos miden temperatura, humedad y presión. El BME680 añade un elemento sensible a gases que entrega una medición de resistencia.

      

      

        ¿Puedo conectar cualquier componente directamente?
        
Depende de la placa y del módulo. Antes de conectarlos, revisa su alimentación, niveles de señal y consumo. Algunos necesitan circuitos de adaptación o una fuente adicional.

      

      

        ¿La página muestra lecturas de sensores en tiempo real?
        
Sí. Al conectar Home Assistant y elegir los sensores, el centro de monitoreo recibe sus cambios y los muestra aquí mismo. Si una señal no está disponible, indica que faltan datos. La simulación es una opción independiente y siempre se identifica.

      

      

        ¿Las ilustraciones muestran las conexiones exactas?
        
Las ilustraciones ayudan a identificar las piezas de forma general. Para montar un circuito, utiliza la ficha y el diagrama del modelo específico que tengas.

      

    

  


  

    

      
ACERCA DEL PROYECTO

      
Un sistema conectado.
Una visión más clara.

    

    

      
IGNIS es un sistema académico para explorar la detección de señales relacionadas con incendios mediante placas ESP32 y sensores de temperatura, humo y flama.

      
La plataforma reúne las lecturas del prototipo, permite observar su evolución y presenta los componentes que intervienen. Home Assistant recibe las señales de las placas y este panel las muestra en vivo.
